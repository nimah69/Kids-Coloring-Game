# پری و دنیای جادویی 🧚

نسخه‌ی آموزشی فارسی و راست‌چین برای کودکان ۳ تا ۷ سال؛ بدون کتابخانه‌ی خارجی، سرور، حساب کاربری یا تبلیغ. این برنامه به‌صورت یک بخش مستقل در مخزن Kids-Coloring-Game اضافه شده تا بازی رنگ‌آمیزی فعلی حفظ شود.

## اجرای محلی
به‌دلیل استفاده از ماژول‌های ES، فایل `index.html` را از طریق یک وب‌سرور محلی ساده اجرا کنید؛ برای نمونه در رایانه `python -m http.server 8000` و سپس مسیر `/peri/`. روی GitHub Pages نیز کار می‌کند.

## انتشار
محتویات این پوشه همراه مخزن منتشر می‌شود و از نشانی `https://nimah69.github.io/Kids-Coloring-Game/peri/` در دسترس خواهد بود، مشروط به فعال بودن GitHub Pages برای مخزن.

## حریم خصوصی
سن، ستاره‌ها، تنظیم صدا و پیشرفت فقط در `localStorage` مرورگر ذخیره می‌شود. حذف داده‌ها با پاک‌کردن داده‌های سایت در تنظیمات مرورگر ممکن است.

## تصویر صفحه
جای‌نگهدار تصویر: پس از آزمایش نهایی روی گوشی، تصویر واقعی صفحه‌ی اصلی را اینجا اضافه کنید.

## توسعه‌های بعدی
نوشتن حروف با انگشت، صداگذاری انسانی آفلاین، فعالیت‌های بیشتر و آیکون‌های PNG استاندارد.
