# دنیای رنگی من | Kids Coloring Game

یک بازی فارسی برای تمرین رنگ‌آمیزی و مهارت‌های پایه‌ی کلاس اول؛ واکنش‌گرا برای گوشی، تبلت و رایانه.

## امکانات
- پنج بازی آموزشی کوتاه با ۳۰ پرسش مقدماتی و بازخورد برای پاسخ درست یا نادرست
- رنگ‌آمیزی خانه‌های شبکه با لمس یا کلیک
- ۸ الگوی آماده: قلب، گل، ماهی، خانه، پروانه، موشک، سیب و نقاشی آزاد
- ۱۲ رنگ، پاک‌کن، بازگشت یک مرحله و پاک‌کردن نقاشی
- سه اندازه شبکه: ۸×۸، ۱۰×۱۰ و ۱۲×۱۲
- ذخیره خودکار نقاشی در حافظه محلی مرورگر
- پنج بازی آموزشی: حرف اول کلمه، شمارش، جمع و تفریق مقدماتی، ادامه‌دادن الگو، شناخت رنگ‌ها و شکل‌ها
- بازخورد پاسخ درست و نادرست، ستاره برای پاسخ درست، و راهنمای صوتی در دستگاه‌های پشتیبانی‌شده
- ذخیره پیشرفت آموزشی در حافظه محلی مرورگر
- بدون کتابخانه خارجی، حساب کاربری یا تبلیغات

## اجرای آنلاین با GitHub Pages
1. وارد مخزن شوید و به **Settings → Pages** بروید.
2. در بخش **Build and deployment**، گزینه **Deploy from a branch** را انتخاب کنید.
3. شاخه `main` و پوشه `/(root)` را انتخاب و ذخیره کنید.
4. پس از انتشار، نشانی معمول پروژه این خواهد بود:
   https://nimah69.github.io/Kids-Coloring-Game/

## اجرا روی گوشی
پس از فعال‌کردن Pages، نشانی سایت را در Chrome باز کنید. برای افزودن میان‌بر، از منوی مرورگر گزینه **Add to Home screen** را انتخاب کنید.

## حریم خصوصی
نقاشی‌ها فقط در حافظه محلی همان مرورگر ذخیره می‌شوند؛ داده‌ای به سرور ارسال نمی‌شود. پاک‌کردن داده‌های مرورگر ممکن است نقاشی‌های ذخیره‌شده را حذف کند.

## وضعیت توسعه
این نسخه، پایه اولیه بازی است. فایل‌های PWA و Service Worker برای کش اولیه و اجرای آفلاین پس از اولین بارگذاری اضافه شده‌اند. رفتار نصب و اجرای آفلاین باید روی گوشی واقعی آزمایش شود؛ وضعیت انتشار GitHub Pages نیز از Settings → Pages قابل بررسی است.
