# دنیای رنگی من | Kids Coloring Game

بازی آموزشی فارسی و راست‌چین برای کودکان کلاس اول؛ بدون کتابخانه‌ی خارجی و بدون ارسال داده به سرور.

## امکانات

- رنگ‌آمیزی شبکه‌ای با ۸ الگو و سه اندازه‌ی ۸×۸، ۱۰×۱۰ و ۱۲×۱۲
- ۱۲ رنگ، پاک‌کن، بازگشت یک عمل، پاک‌کردن نقاشی و رنگ‌آمیزی با لمس/کشیدن یا ماوس
- ذخیره‌ی جداگانه‌ی نقاشی برای هر ترکیب الگو و اندازه و مهاجرت داده‌های قدیمی
- راهنمای رنگ‌آمیزی مرحله‌ای و بررسی تطابق، شامل خانه‌های بیرون از شکل
- پنج بازی آموزشی با دست‌کم ۱۵ سؤال در هر مهارت (مجموع ۷۵ سؤال پایه)
- دشواری تطبیقی، بازخورد پاسخ، پخش صوتی در صورت وجود صدای فارسی
- گزارش والدین، سه نمایه‌ی کودک و بازنشانی پیشرفت آموزشی
- طراحی واکنش‌گرا، RTL، برچسب‌های دسترس‌پذیری و PWA با Service Worker نسخه‌دار
- آزمون خودکار با GitHub Actions در هر push و pull request

## اجرای آنلاین

[بازکردن بازی در GitHub Pages](https://nimah69.github.io/Kids-Coloring-Game/)

## اجرای محلی

فایل‌ها را در یک وب‌سرور محلی اجرا کنید؛ برای نمونه از افزونه‌ی Live Server در ویرایشگر استفاده کنید. اجرای مستقیم از مسیر `file://` برای آزمون Service Worker مناسب نیست.

## آزمون کیفیت

با Node.js نسخه‌ی ۲۰ یا جدیدتر:

```sh
node tests/quality-check.mjs
```

این آزمون نحو JavaScript، عناصر ضروری، الگوهای متقارن، ساختار ذخیره‌سازی، بانک پرسش‌ها، آیکون‌های PWA و سیاست امنیت محتوا را بررسی می‌کند.

## حریم خصوصی

نقاشی‌ها و پیشرفت آموزشی فقط در حافظه‌ی محلی مرورگر ذخیره می‌شوند. برنامه هیچ داده‌ای را به سرور ارسال نمی‌کند.

## وضعیت فونت و آیکون‌ها

CSS از نام فونت Vazirmatn استفاده می‌کند، اما فایل فونت WOFF2 هنوز در مخزن قرار نگرفته است؛ در نبود فونت نصب‌شده، مرورگر از فونت جایگزین استفاده می‌کند. آیکون‌ها فعلاً SVG هستند؛ نسخه‌های PNG مستقل ۱۹۲×۱۹۲ و ۵۱۲×۵۱۲ و Apple Touch Icon از نوع PNG هنوز اضافه نشده‌اند.

## مجوز

پروژه تحت مجوز MIT است. اگر فایل فونت Vazirmatn اضافه شود، مجوز OFL خود فونت نیز باید همراه آن منتشر شود.


## پروژه‌ی تازه: پری و دنیای جادویی 🧚

نسخه‌ی آزمایشی بازی‌های آموزشی برای کودکان ۳ تا ۷ سال در پوشه‌ی [`peri/`](./peri/) قرار دارد. پس از ادغام شاخه، از مسیر [اجرای پری و دنیای جادویی](./peri/) بازش کنید.
